# Звітність та Аналітика (Reports)
**Слоган:** "Дані, що допомагають заробляти більше."

Система не просто збирає дані, а перетворює їх на інсайти для прийняття рішень.

## 1. Оперативна статистика (Operational Stats)
Моніторинг виконання планів у реальному часі.
*   **Пропорційний план:** Автоматичний розрахунок плану на поточний момент (наприклад, якщо пройшло 3 дні тижня, план складає 3/7 від норми).
*   **Прогнозування:** Розрахунок очікуваного результату на кінець періоду на основі поточної динаміки.
*   **Деталізація по днях:** Розкриття історії роботи авто за період з відображенням конкретних водіїв.
*   **Облік простою:** Чітке відображення днів, коли авто не працювало.
*   **Експорт:** Завантаження звіту в Excel (.xlsx) з повним форматуванням.

## 2. Виконання нормативів (Performance Report)
Історичний аналіз ефективності парку.
*   **Факт vs План:** Порівняння реальних показників з встановленими нормативами (KPI).
*   **Точний розрахунок:** Врахування кількості днів у кожному місяці.
*   **Візуалізація:** Кольорове кодування відсотків виконання (Зелений/Жовтий/Червоний).

## 3. Аналітика Автопарку (Fleet Analytics)

### Економіка авто (Vehicle Earnings)
Детальний аналіз прибутковості кожної одиниці техніки (Unit Economics).
*   **P&L (Profit and Loss):** Розрахунок чистого прибутку авто за формулою: `(Вал - Комісія - ЗП водія) - Витрати на авто`.
*   **KPI:** Пробіг, Кількість поїздок, Середній чек, Ефективність (Грн/км).
*   **Рейтинг:** Топ найприбутковіших та найбільш збиткових автомобілів.

### Технічний стан (Maintenance Report)
Зведений звіт про обслуговування.
*   **Регламентні роботи:** Які авто потребують ТО найближчим часом (прогноз по пробігу).
*   **Витрати на ремонти:** Аналіз вартості володіння (TCO). Які авто ламаються найчастіше?

## 4. Звіт по поїздках
Показує всі переміщення авто за обраний період.
*   Час початку/кінця руху.
*   Пробіг.
*   Середня та максимальна швидкість.
*   Адреси зупинок.

## 5. Звіт по паливу
Дозволяє контролювати заправки та зливи.
> Для точності цього звіту необхідне калібрування бака (тарування).

**Основні показники:**
*   Початковий/кінцевий залишок.
*   Витрачено в русі / на холостому ходу.
*   Середня витрата (л/100км).

# Генерація звітів

Отримайте повну картину використання вашого автопарку.

## Типи звітів

### 1. Звіт по поїздках
Показує всі переміщення авто за обраний період.
*   Час початку/кінця руху.
*   Пробіг.
*   Середня та максимальна швидкість.
*   Адреси зупинок.

### 2. Звіт по паливу
Дозволяє контролювати заправки та зливи.
> Для точності цього звіту необхідне калібрування бака (тарування).

**Основні показники:**
*   Початковий/кінцевий залишок.
*   Витрачено в русі / на холостому ходу.
*   Середня витрата (л/100км).

## Експорт даних
Ви можете завантажити будь-який звіт у зручному форматі:
*   `PDF` - для друку.
*   `Excel (XLSX)` - для подальшої обробки.
*   `API` - для інтеграції з 1С або CRM.

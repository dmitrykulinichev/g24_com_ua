# Мобільність та Технології
**Слоган:** "Ваш офіс у кишені."

Garage24 — це сучасний веб-додаток (PWA), який забезпечує повноцінну роботу з будь-якого пристрою. Вам не потрібно встановлювати окремі програми з App Store чи Google Play.

## Технологічні переваги

### SPA (Single Page Application)
Система працює як додаток: сторінки не перезавантажуються, переходи миттєві. Це економить трафік і час.

### Адаптивний дизайн (Mobile First)
Інтерфейс автоматично підлаштовується під екрани смартфонів, планшетів та ноутбуків.
*   **Менеджер:** Може керувати парком, перебуваючи в дорозі.
*   **Водій:** Має зручний особистий кабінет для перегляду балансу та графіку.
*   **Механік:** Може вносити дані про ремонт прямо біля автомобіля.

### Темна тема (Dark Mode)
Вбудована підтримка темного режиму для комфортної роботи диспетчерів у нічні зміни. Система автоматично перемикається залежно від налаштувань вашого пристрою.

### PWA (Progressive Web App)
Ви можете додати іконку Garage24 на головний екран телефону, і система буде працювати як нативний додаток (без рамок браузера).

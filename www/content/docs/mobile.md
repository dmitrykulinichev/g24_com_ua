# Мобільність та Доступність
**Слоган:** "Офіс у вашій кишені"

Система побудована як сучасний веб-додаток (SPA - Single Page Application), що забезпечує швидку роботу та адаптивність.

## Детальні можливості

### Адаптивний дизайн
Інтерфейс автоматично підлаштовується під екрани смартфонів, планшетів та ноутбуків. Менеджер може керувати парком, перебуваючи в дорозі.

### PWA (Progressive Web App)
Можливість встановити систему як додаток на телефон. Швидке завантаження навіть при поганому інтернеті.

### Темна тема
Вбудована підтримка темного режиму для комфортної роботи в нічний час (актуально для диспетчерів).

# Екосистема Telegram
**Слоган:** "Керуйте парком через месенджер."

Ми створили потужного Telegram-бота, який стає персональним асистентом для кожного водія та менеджера. Це дозволяє зменшити кількість дзвінків та рутинних запитань.

{{screenshot file="driver_telegram_connect_modal.png" title="Telegram Connection Modal"}}

## Для Водіїв

### 1. Підключення
Водій сканує QR-код у своєму профілі або переходить за унікальним посиланням. Система автоматично ідентифікує його.

### 2. Особистий кабінет у чаті
Бот надає миттєвий доступ до важливої інформації:
*   **Баланс:** Перевірка поточного фінансового стану (скільки я заробив? скільки я винен?).
*   **Графік:** Перегляд своїх змін на найближчий тиждень.
*   **Борги:** Автоматичні нагадування про необхідність погасити заборгованість.

### 3. Ручні замовлення (Manual Trips)
Водії можуть самостійно фіксувати поїздки "від бордюру" без дзвінка диспетчеру.
*   **Команда:** `[номер авто] рука [сума]` (наприклад: `1234 рука 150`).
*   **Редагування:** Якщо водій помилився, він може просто відредагувати повідомлення в Telegram, і сума оновиться в системі автоматично.

### 4. Звіти про поломки
Можливість відправити фото пошкодження або чека з заправки прямо в чат.

## Для Менеджерів

### 1. Сповіщення
Система надсилає важливі повідомлення в робочі чати:
*   Новий звіт про поломку.
*   Водій вийшов на лінію.
*   Критичний залишок на балансі водія.

### 2. Логування (Telegram Logs)
Всі повідомлення зберігаються в системі. Ви завжди можете перевірити, що і коли писав водій, навіть якщо він видалив повідомлення у себе.

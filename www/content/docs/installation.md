Цей розділ допоможе вам підключити перші GPS-трекери до системи G24.

## 1. Підготовка обладнання
Перед початком роботи переконайтеся, що у вас є:
*   GPS-трекер (підтримувані моделі: Teltonika, Bitrek, Queclink).
*   SIM-карта з підключеним інтернетом (GPRS/4G).
*   Доступ до бортової мережі автомобіля (12V/24V).

## 2. Схема підключення
Підключіть трекер згідно зі схемою нижче:

![Схема підключення](/assets/img/docs/tracker.svg)

## 3. Налаштування трекера
Налаштуйте трекер на сервер G24:
*   **IP адреса:** `192.168.1.10` (приклад)
*   **Порт:** `5027`
*   **APN:** згідно з вашим оператором.

> **Важливо:** Переконайтеся, що трекер "бачить" супутники (індикатор GPS блимає зеленим).

## 4. Додавання в систему
1.  Зайдіть в адмін-панель.
2.  Натисніть кнопку **"Додати об'єкт"**.
3.  Введіть IMEI трекера та назву авто.

```json
{
  "imei": "123456789012345",
  "name": "Renault Master AA1234BB"
}
```

Після цього авто з'явиться на карті протягом 5 хвилин.

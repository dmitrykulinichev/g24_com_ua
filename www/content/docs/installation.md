# Початок роботи

Garage24 — це хмарне рішення (SaaS), тому вам не потрібно встановлювати складне програмне забезпечення на свої сервери. Все працює у браузері.

## 1. Реєстрація
Щоб почати роботу, вам потрібно створити обліковий запис адміністратора.
1.  Перейдіть на сторінку реєстрації.
2.  Введіть назву вашого автопарку.
3.  Вкажіть контактні дані власника.

## 2. Первинне налаштування
Після входу в систему виконайте базові налаштування:
*   **Створіть автопарк:** Додайте перші автомобілі вручну або імпортуйте їх з Excel.
*   **Додайте водіїв:** Створіть профілі водіїв або надішліть їм посилання для самостійної реєстрації.
*   **Налаштуйте ролі:** Якщо у вас є менеджери або механіки, створіть для них окремі акаунти з відповідними правами доступу.

## 3. Інтеграція з Uklon (опціонально)
Якщо ви працюєте з Uklon, підключіть API для автоматичного завантаження поїздок:
1.  Перейдіть в **"Налаштування" -> "Uklon"**.
2.  Введіть ключі API від кабінету партнера Uklon.
3.  Натисніть "Синхронізувати".
4.  Використовуйте функцію **Link Fleet** для зв'язування авто.

Тепер ваша система готова до роботи!

# Маркетинг та Рекрутинг (Marketing)
**Слоган:** "Залучайте найкращих водіїв автоматично."

Інструменти для створення бренду роботодавця та автоматизації найму персоналу.

{{screenshot file="marketing_landing_settings.png" title="Landing Page Settings"}}

## Публічна сторінка (Landing Page)
Ваша візитна картка в інтернеті. Система дозволяє налаштувати лендінг для реєстрації кандидатів без знання коду.
*   **Конструктор:** Налаштування заголовків, описів переваг, контактних даних у розділі `LandingSettings`.
*   **Брендування:** Завантаження логотипу та фонових зображень.
*   **Форма реєстрації:** Кандидат заповнює анкету, і його дані автоматично потрапляють у систему як "Новий водій".

## Матеріали (Materials)
Готові до друку маркетингові матеріали.
*   **QR-код для рекрутингу:** Система генерує макет наліпки "Хочеш працювати водієм? Скануй".
*   **Призначення:** Розміщення в салонах авто для пасажирів. Пасажир сканує код і потрапляє на вашу публічну сторінку.

{{screenshot file="marketing_materials_qr.png" title="Recruiting QR Code"}}

## Інструменти менеджера
*   **Registration Link:** Швидке копіювання посилання на форму реєстрації для відправки в месенджери.

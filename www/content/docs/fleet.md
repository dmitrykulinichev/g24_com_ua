# Управління автопарком (Fleet Management)
**Слоган:** "Цифровий паспорт кожного автомобіля."

Модуль дозволяє вести повний облік транспортних засобів, перетворюючи хаотичні дані на структуровану картотеку активів.

{{screenshot file="fleet_vehicles_list.png" title="Fleet Vehicles List"}}

## Електронна картка автомобіля
*   **Основні дані:** Держ. номер, VIN, Марка, Модель, Рік випуску.
*   **Розширені характеристики:** Тип кузова, Колір, Рівень комфорту, Кількість місць, Типи палива (мультиселект).
*   **Creatable Select:** Можливість створення нових марок та моделей "на льоту" прямо у формі.

{{screenshot file="fleet_vehicle_card_modal.png" title="Vehicle Card Modal"}}

## Масовий імпорт (Import)
Швидке завантаження бази автомобілів з Excel/CSV файлів.
*   **Формати:** `.xlsx`, `.xls`, `.csv`.
*   **Валідація:** Система автоматично перевіряє дублікати (VIN, держ. номер) та коректність даних перед збереженням.
*   **Історія:** Збереження логів імпорту (Import Batches) з деталізацією по кожному рядку.

{{screenshot file="fleet_import_modal.png" title="Vehicle Import Modal"}}

## Документи та Життєвий цикл
*   **Vehicle Assignments:** Повна історія закріплення водіїв (хто керував авто в конкретний день).
*   **Документи:** Зберігання та моніторинг термінів дії страховок та ліцензій.
*   **Історія пробігу:** Ручне оновлення через модальне вікно `UpdateMileageModal` з історією змін.

{{screenshot file="fleet_documents_list.png" title="Fleet Documents"}}

## Доступні дії (Модальні вікна)
Система надає швидкий доступ до ключових операцій прямо зі списку авто:
*   **VehicleFormModal:** Створення нового автомобіля або редагування існуючого.
*   **Update Mileage:** Ручне оновлення пробігу.
*   **Assign/Unassign Driver:** Призначення або зняття водія з авто.
*   **Quick Maintenance:** Швидке створення запису про ТО.
*   **Print QR:** Перегляд та друк унікального QR-коду автомобіля.

## QR-ідентифікація
Система генерує унікальний стікер з QR-кодом для кожного авто.
*   **Водій:** Сканує код -> повідомляє про проблему.
*   **Механік:** Сканує код -> бачить історію ремонтів.

## Інтеграція
Модальне вікно `VehicleIntegrationModal` дозволяє налаштувати зв'язок з Uklon для синхронізації даних.

# Адміністрування та Безпека
**Слоган:** "Повний контроль доступу"

Інструменти для налаштування системи під специфіку конкретного бізнесу та захисту даних.

## Детальні можливості

### Рольова модель (RBAC)
*   **Super Admin:** Повний доступ.
*   **Manager:** Управління водіями та графіком, але без доступу до налаштувань системи.
*   **Mechanic:** Тільки модуль ремонтів та авто.
*   **Accountant:** Тільки фінанси.

### Аудит дій (Activity Logs)
"Чорна скринька" системи. Записує кожну дію: хто змінив пробіг? хто видалив транзакцію? хто змінив статус водія?
Дозволяє проводити розслідування інцидентів.

### Налаштування регламентів
Власник сам задає правила: як часто міняти мастило (наприклад, кожні 8000 км), які типи змін використовувати.

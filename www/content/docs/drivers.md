# Робота з водіями

Система G24 дозволяє вести облік водіїв та контролювати їх ефективність.

## Створення профілю водія
Щоб додати водія:
1.  Перейдіть у меню **"Довідники" -> "Водії"**.
2.  Натисніть **"Створити"**.
3.  Заповніть поля: ПІБ, телефон, номер посвідчення.

### Призначення на авто
Ви можете закріпити водія за автомобілем двома способами:
*   **Вручну:** Через диспетчерську панель.
*   **Автоматично:** За допомогою RFID-карток (якщо в авто встановлено зчитувач).

## Рейтинг водіння (Eco Driving)
Система аналізує стиль водіння за такими параметрами:
- Різкі прискорення
- Різкі гальмування
- Входження в поворот на швидкості

| Оцінка | Опис |
| :--- | :--- |
| **A (90-100)** | Відмінно, економний стиль |
| **B (70-89)** | Добре, є дрібні порушення |
| **C (<70)** | Агресивне водіння, перевитрата пального |

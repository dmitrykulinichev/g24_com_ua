# Інтеграції (Uklon API)
**Слоган:** "Автоматизація рутини"

Глибока інтеграція з API сервісу Uklon (та потенційно інших агрегаторів) для автоматичного обміну даними.

## Детальні можливості

### Синхронізація замовлень
*   Система автоматично завантажує всі поїздки: маршрут, вартість, час, дистанцію.
*   Немає потреби вручну переносити дані з кабінету Uklon.

### Синхронізація сутностей
*   Автоматичне створення водіїв та авто в системі на основі даних з Uklon.
*   Зв'язування (Mapping) внутрішніх ID з ID агрегатора.

### Контроль ефективності
Порівняння планових показників з фактичними даними від агрегатора.

# Журнал поїздок, графік роботи та внутрішні покращення

![Картка автомобіля в мобільному додатку](/assets/img/blog/app-vehicle-card.png)

## Журнал поїздок: уся хронологія без гортання по днях

Невелике, але помітне покращення: список ручних поїздок у мобільному додатку тепер відображає всі записи одразу — без навігаційної панелі «вперед/назад по датах».

### Чому змінили

Раніше сторінка відкривалась на сьогодні і показувала лише поїздки за обраний день. Щоб побачити позавчора — треба було двічі натиснути «назад». Зручно, коли поїздок сотні й потрібна конкретна дата. Незручно, коли їх десять і хочеться просто переглянути все одним поглядом.

### Як тепер виглядає

Список зібраний у хронологічні групи:

- **Сьогодні** — поїздки поточного дня вгорі
- **Вчора** — попередній день
- Конкретна дата — для всього старшого: «1 липня», «28 червня» і так далі

Кожен рядок показує суму, кілометраж (якщо вказано), час і джерело — Додаток, Бот або Веб. Під головним рядком — номер і марка автомобіля.

Кнопки редагування і видалення залишились — доступні протягом 24 годин після додавання.

## Графік роботи: три вигляди, всі парки одразу

Повністю перероблена сторінка «Графік» у мобільному додатку. Тепер доступні три вигляди — перемикаються кнопкою у заголовку.

### Місячний вигляд — таблиця-календар

Вигляд за замовчуванням при відкритті. Класичний сітчастий календар, де у кожній клітинці відображається не лише число, а й номер автомобіля на яке заплановане чергування. Якщо водій працює в кількох парках — чергування кожного позначені власним кольором: перший парк — синій, другий — зелений, третій — помаранчевий і т. д. Легенда кольорів показується зверху.

Тап на будь-який день — перехід у тижневий вигляд на той тиждень.

### Два тижні — табличне подання

Новий вигляд: зліва шкала днів тижня (Пн–Нд), праворуч два стовпчики — поточний і наступний тиждень. Рядки вирівняні: понеділок першого тижня завжди навпроти понеділка другого. Дає змогу одним поглядом охопити 14 днів і порівняти розклад двох тижнів.

### Тижневий вигляд — деталі по днях

Вертикальний список семи днів із повною інформацією: часовий слот зміни, іконка ранок/день/ніч, марка й номер авто, назва парку (якщо парків кілька), нотатки, тип (зміна / ТО / ремонт).

### Навігація

- Стрілки «назад/вперед» переміщають на тиждень, два тижні або місяць залежно від активного вигляду
- Кнопка з назвою поточного діапазону відкриває компактний picker для швидкого переходу до довільної дати
- Кнопка «сьогодні» з'являється лише коли видимий діапазон не містить поточного дня

### Мультипарковість

Усі чергування завантажуються паралельно з кожного парку водія — без необхідності перемикатися між парками вручну. Кожен `park × місяць` кешується окремо, тому навігація по місяцях майже миттєва після першого завантаження.

## Технічна частина: тести й рефакторинг

**Тести бекенду.** Написали повний набір автоматичних тестів для всіх ендпоінтів мобільного API — авторизація, профіль, автомобілі, пробіг, документи, призначення, поїздки, витрати, звернення, SOS, push-токени, новини. 33 тести з повним middleware-стеком.

**Тести фронтенду.** Покриття для всіх методів `FleetApi`: URL, HTTP-метод, тіло запиту, розпаковування відповіді. Включно з `getScheduleForPark` — тест перевіряє що запит до стороннього парку іде з правильним `X-Park-Id` заголовком.

**Рефакторинг контролерів.** Великий `DriverVehicleController` розбитий на чотири менших з чіткою відповідальністю: транспортний засіб, пробіг, документи, призначення.

**Уніфікований формат відповідей API.** Усі ендпоінти мобільного API повертають `{ success, data }`. Будь-яка регресія при наступних змінах буде помічена автоматичними тестами.

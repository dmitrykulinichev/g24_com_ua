# Зовнішній вигляд

Налаштуйте інтерфейс Garage24 під свій комфорт: обирайте світлу чи темну тему та керуйте додатковими візуальними параметрами системи.

![Зовнішній вигляд](screenshots/light/desktop/tab_settings_appearance_main.png)

Ваш робочий простір має бути зручним для ваших очей. Ми пропонуємо гнучкі можливості персоналізації, щоб зробити роботу з системою максимально приємною.

## Основні можливості

*   **Вибір теми:** Обирайте між світлою (денною) та темною (нічною) темою оформлення. Темна тема допомагає знизити втому очей при роботі ввечері або в умовах низького освітлення.
*   **Інструменти для професіоналів:** Керуйте візуальними помічниками інтерфейсу, такими як UI Inspector, що допомагають тонко налаштувати відображення елементів системи.
*   **Комфорт для кожного:** Персоналізація інтерфейсу дозволяє кожному менеджеру створити свій ідеальний робочий простір.

# Логи інтеграції Uklon

Повний технічний контроль вашої інтеграції: переглядайте історію запитів та відповідей до API Uklon для миттєвої діагностики та забезпечення стабільності зв'язку.

![Логи Uklon](screenshots/light/desktop/page_uklon_logs_main.png)

Розділ «Логи інтеграції Uklon» — це ваш надійний помічник у моніторингу технічного стану зв’язку з платформою Uklon. Якщо ви помітили будь-які неточності в даних, цей журнал допоможе знайти першопричину та оперативно виправити її.

## Основні можливості

*   **Повний аудит взаємодії:** Відстежуйте історію всіх запитів та відповідей між Garage24 та API Uklon для розуміння того, що саме відбувається в фонових процесах.
*   **Гнучкий пошук:** Знаходьте потрібні записи за endpoint, URL, статусом відповіді або іншими параметрами за лічені секунди.
*   **Детальний аналіз:** Кожен запис можна відкрити для перегляду технічних деталей, що критично важливо для виявлення та усунення помилок у передачі даних.
*   **Актуальність даних:** Система підтримує ручне оновлення списку логів, тому ви завжди будете працювати з найсвіжішою інформацією.
*   **Комфорт роботи:** Пагінація списку забезпечує зручність при роботі навіть з великою кількістю логів за тривалий час.

## Робота з логами

### Діагностика інтеграції
Завдяки детальному перегляду логів ви зможете зрозуміти, чи була успішною передача даних. Це дозволяє вчасно реагувати на будь-які технічні збої, забезпечуючи безперебійну роботу вашого автопарку з платформою Uklon.

### Статистика та контроль
Журнал логів — це гарантія прозорості та стабільності вашої інтеграції. Ви завжди можете бути впевнені в тому, що всі запити до Uklon обробляються належним чином, а в разі виникнення проблем у вас під рукою є всі необхідні інструменти для їх вирішення.

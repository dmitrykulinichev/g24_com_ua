# Налаштування Uklon

Налаштуйте пряму інтеграцію вашого автопарку з сервісом Uklon: безпечно керуйте ключами API та параметрами синхронізації в єдиному центрі управління.

![Налаштування Uklon](screenshots/light/desktop/page_uklon_settings_main.png)

Розділ «Налаштування Uklon» — це місток між вашою внутрішньою системою Garage24 та платформою Uklon. Правильне налаштування інтеграції забезпечує безперебійний обмін даними, дозволяючи вам автоматизувати процеси та завжди володіти найактуальнішою інформацією.

## Основні можливості

*   **Безпека інтеграції:** Керуйте ключами доступу до API в безпечному середовищі, що гарантує захищеність вашого підключення до сервісу Uklon.
*   **Гнучке налаштування синхронізації:** Встановлюйте параметри передачі даних, щоб система працювала саме так, як потрібно для вашого бізнесу.
*   **Центр управління:** Всі налаштування інтеграції зібрані в одному місці — це спрощує технічне обслуговування зв'язку та дозволяє оперативно вносити зміни у разі потреби.
*   **Стабільність зв'язку:** Правильно налаштована інтеграція — запорука того, що вся статистика по поїздках та доході автоматично надходитиме до Garage24 без затримок.

## Як почати роботу

У цьому розділі ви можете вказати всі необхідні технічні параметри, надані платформою Uklon. Інтерфейс максимально простий: достатньо зберегти конфігураційні дані, і система автоматично розпочне синхронізацію, забезпечуючи повноцінну роботу з вашим автопарком.

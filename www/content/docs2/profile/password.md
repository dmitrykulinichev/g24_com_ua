# Зміна паролю

Забезпечте надійний захист вашого акаунта: регулярно оновлюйте пароль для запобігання несанкціонованому доступу до системи.

![Зміна паролю](screenshots/light/desktop/tab_profile_password_main.png)

Безпека починається з вас. Ми рекомендуємо використовувати надійні паролі та оновлювати їх за потреби.

## Ваші можливості

*   **Безпечна зміна:** Процес передбачає введення поточного пароля для підтвердження того, що саме ви вносите зміни.
*   **Валідація:** Система гарантує правильність введення нового пароля завдяки його подвійному підтвердженню, виключаючи помилки друку.
*   **Надійність:** Ви завжди можете бути впевнені, що ваш доступ захищений новим, відомим лише вам паролем.

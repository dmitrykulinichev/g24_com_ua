# Виконання нормативів

Порівнюйте фактичні результати з плановими KPI та визначайте найефективніші одиниці вашого автопарку для оптимізації доходів.

![Виконання нормативів](screenshots/light/desktop/tab_reports_performance_main.png)

Цей аналітичний звіт дає глибинне розуміння ефективності кожного автомобіля та водія, допомагаючи виявити сильні та слабкі сторони вашої бізнес-моделі.

## Основні можливості

*   **KPI Аналіз:** Оцінюйте ефективність за ключовими показниками — доходом та кількістю виконаних поїздок.
*   **Гнучка фільтрація:** Аналізуйте дані за будь-який період, який вас цікавить.
*   **Порівняння з нормативами:** Бачте реальну картину: наскільки фактичні показники відповідають встановленим вами KPI.
*   **Кольоровий статус:** Індикація (зелений/жовтий/червоний) миттєво підсвічує авто, що потребують уваги.
*   **Облік активності:** Бачте унікальних водіїв та дні простою для кожного транспортного засобу за обраний проміжок часу.
*   **Щоденна деталізація:** Аналізуйте динаміку роботи авто в межах обраного періоду.
*   **Підсумкова аналітика:** Отримуйте агреговані дані по всьому парку для глобального планування.
*   **Експорт в Excel:** Зберігайте аналітичні звіти для звітності чи подальшого моделювання.

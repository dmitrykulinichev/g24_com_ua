# Технічне обслуговування (Звіт)

Тримайте автопарк у справному стані: слідкуйте за регламентними роботами, виявляйте критичні проблеми та плануйте ремонти завчасно.

![Звіт по ТО](screenshots/light/desktop/tab_reports_maintenance_main.png)

Цей звіт надає повну видимість технічного стану вашого парку, допомагаючи уникнути непередбачених поломок та оптимізувати витрати на обслуговування.

## Основні можливості

*   **Моніторинг регламентів:** Слідкуйте за станом планового ТО для кожного автомобіля в автопарку.
*   **Індикація критичності:** Система підсвічує статус робіт (Прострочено, Критично, Попередження, В нормі), щоб ви фокусувалися на головному.
*   **Гнучке групування:** Фільтруйте автомобілі за найгіршим статусом їх регламентних робіт для оперативного прийняття рішень.
*   **Швидкий пошук:** Знаходьте потрібне авто за держномером або моделлю.
*   **Сортування:** Вибудовуйте список авто за пріоритетністю проблем або кількістю відкритих питань.
*   **Детальна картка авто:** Переглядайте повний перелік усіх запланованих робіт та залишку пробігу/часу до них по кожному транспортному засобу.
*   **Статистична панель:** Бачте загальну кількість авто та розподіл робіт за різними статусами в одному вікні.
*   **Ручне оновлення:** Отримуйте найактуальніші дані звіту в будь-який момент одним натисканням.

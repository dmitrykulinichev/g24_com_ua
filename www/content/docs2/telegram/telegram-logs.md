# Логи Telegram

Повний технічний контроль комунікації: відстежуйте історію запитів та відповідей вашого Telegram-бота для гарантії стабільної доставки повідомлень водіям.

![Логи Telegram](screenshots/light/desktop/page_telegram_logs_main.png)

Логи Telegram — це ваш інструмент для швидкої діагностики. Якщо виникають питання щодо доставки повідомлень, цей розділ дозволить миттєво з'ясувати причину та вжити необхідних заходів для відновлення зв'язку.

## Основні можливості

*   **Повна історія взаємодій:** Переглядайте детальний лог усіх запитів системи до Telegram та відповідей від сервісу.
*   **Гнучка фільтрація:** Швидко відбирайте логи за статусом, типом дії або конкретним діапазоном дат для швидкого пошуку інцидентів.
*   **Потужний пошук:** Знаходьте потрібний запис у журналі за лічені секунди.
*   **Деталізація подій:** Кожен запис можна відкрити для перегляду технічних деталей, що важливо для глибокого аналізу помилок доставки.
*   **Актуальність даних:** Система підтримує ручне оновлення списку логів, щоб ви завжди бачили найсвіжішу інформацію.
*   **Масштабованість:** Зручна пагінація дозволяє комфортно працювати навіть з великою кількістю логів за тривалий період.

## Робота з логами

### Діагностика помилок
За допомогою детального перегляду кожного логу ви можете легко виявити технічні проблеми, такі як блокування бота водієм або помилки в API Telegram, та оперативно їх усунути.

### Аналіз станів
Система чітко відображає успішні та невдалі спроби доставки, що допомагає оцінити якість комунікації вашого парку з водіями та вчасно реагувати на збої.

# Налаштування лендінгу

Ваша посадова сторінка для залучення водіїв: керуйте брендуванням, контентом та актуальними пропозиціями вашого парку через зручну панель налаштувань.

Garage24 дозволяє створити професійну сторінку для водіїв, яка виглядає сучасно та викликає довіру. Налаштовуйте все під свій бренд без участі програмістів.

Виберіть напрямок налаштувань:

*   **[Загальні налаштування](./landing-general.md)**: Брендування, контактна інформація та ключові переваги вашого парку.
*   **[Новини та акції](./landing-news.md)**: Публікація бонусних програм та спеціальних пропозицій для водіїв.

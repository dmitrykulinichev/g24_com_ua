# Мови лендінгу (app/I18n)

Українська — основна, на корені адреси (`/features`); інші мови — з префіксом (`/en/features`, `/ru/features`).
План і стан — `workspace/plans/landing-i18n-plan.md`.

## Як влаштовано

| Що | Де | Відповідальність |
|---|---|---|
| Мови, основна, відкриті, перекладені адреси | `config/i18n.php`, `LocaleConfig` | лише конфіг |
| Мова запиту з адреси | `LocaleResolver` (у `index.php`, до маршрутизації) | знімає префікс — маршрути й контролери одні для всіх мов; `/uk/…` → 301; закрита мова → 404; `/api/…` — мова з `X-Locale` |
| Мова й адреса поточної сторінки | `Locale` | стан запиту |
| Тексти | `lang/{uk,en,ru}.php`, `Translator` | ключ через крапку, `:плейсхолдери`; немає перекладу → українська; немає й там → ключ |
| Адреси з мовою | `LocalizedUrl` | `to()`, `canonical()`, `alternates()` (hreflang, перемикач, мапа сайту) |
| Помічники в Blade | `helpers.php` | `t()`, `t_list()`, `t_json()`, `lurl()`, `locale()` |

## Правила

- Внутрішнє посилання — завжди `lurl('/pricing')`, не `/pricing`: інакше з англійської сторінки перекине на українську.
- Текст на сторінці — `t('ключ')`; ключ спершу в `lang/uk.php` (основа), потім переклади.
- Запит до `/api` з JS — `apiFetch()` (передає мову сторінки в `X-Locale`); лендінг пересилає її в СААС (`SpaApiService`).
- **Відкрити мову** відвідувачам — `LANDING_LOCALES=uk,en,ru` у `.env`. Закриту видно лише з `LANDING_LOCALES_PREVIEW=true`.
- **Перекладена сторінка** — додати її адресу в `localized_paths` (`config/i18n.php`): лише тоді canonical поточною
  мовою, hreflang і мовні адреси в мапі сайту. Неперекладена під `/en` показує український текст з canonical на
  українську адресу — без дублів для пошуковиків.

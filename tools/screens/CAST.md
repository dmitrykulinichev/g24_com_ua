# Хто в кадрі

Щоб через тижні перезняти скріни й ролики тими самими людьми й даними, а не вигадувати заново.
Тут записано, ким знято кожен скрін застосунку: водій, номер, як увійти, парк, авто і з якого стану
починати. Скрін кабінету — те саме, якщо в кадрі конкретні водії чи авто.

**Правила**

- Новий скрін → рядок у таблиці «Скріни» нижче + `scenario` у `landing/www/content/screens.json` з
  ім'ям людини з цього реєстру.
- Лише парк «Київ» (park 15). DiDiDrive2 не чіпаємо. Рецензентів сторів (Reviewer …, AA1111BB,
  KA9002GR) у кадр не беремо.
- Номери для входу без пароля — тестові номери Firebase з фіксованим кодом (`kmp/docs/testing.md`):
  їх агент вводить сам. Паролі не записуємо: їх вводить лише власник (менеджер паролів).
- Сценарій змінив стан людини (зареєстрував, прийняв авто…) → оновити колонку «Стан» тут.

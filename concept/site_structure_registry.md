# Реєстр структури сайту Garage24

Цей документ містить детальний опис структури сайту, всіх сторінок, їх функціональних блоків, модальних вікон та зв'язків між ними. Призначений для обговорення з маркетологами та розробниками.

---

## 1. Загальна структура (Sitemap)

### Основні сторінки
| URL | Контролер | View (Blade) | Опис |
|---|---|---|---|
| `/` | `LandingController@index` | `landing.blade.php` | Головна сторінка (Landing Page). Презентація продукту, болі клієнта, рішення. |
| `/features` | `FeaturesController@index` | `features.blade.php` | Сторінка "Можливості". Детальний опис функціоналу по категоріях. |
| `/target` | `TargetController@index` | `target.blade.php` | Сторінка "Кому підійде". Сегментація аудиторії (партнери, інвестори, операціоністи). |
| `/pricing` | `PricingController@index` | `pricing.blade.php` | Сторінка "Тарифи". Порівняння планів, ціни, вибір тарифу. |
| `/contacts` | `ContactsController@index` | `contacts.blade.php` | Сторінка "Контакти". Форма зворотного зв'язку, контакти підтримки. |
| `/blog` | `BlogController@index` | `blog.index.blade.php` | Головна сторінка блогу. Список статей. |
| `/blog/{slug}` | `BlogController@show` | `blog.post.blade.php` | Сторінка окремої статті блогу. |
| `/docs` | `DocsController@index` | `docs.index.blade.php` | Головна сторінка документації. Категорії та пошук. |
| `/docs/{slug}` | `DocsController@show` | `docs.page.blade.php` | Сторінка окремої статті документації. |

### API та Службові маршрути
| URL | Метод | Контролер | Опис |
|---|---|---|---|
| `/api/lead` | POST | `LeadController@submit` | Обробка форми заявки (Landing, Pricing, Contacts). Валідація, reCAPTCHA, збереження в CRM/Telegram. |
| `/api/page/{slug}` | GET | `PageController@apiShow` | Отримання контенту статичних сторінок (Privacy, Terms) для модальних вікон. |
| `/api/docs/search` | GET | `SearchController@search` | Пошук по документації. |
| `/api/blog/search` | GET | `SearchController@searchBlog` | Пошук по блогу. |

## 2. Детальний опис сторінок та смислових блоків

### 2.1. Головна сторінка (`/`)
**Мета:** Конвертація відвідувача в ліда (заявка на підключення).
**View:** `landing.blade.php`

**Смислові блоки:**
1.  **Header (`partials.header`)**: Логотип, навігація, кнопка входу в додаток ("В гараж").
2.  **Hero Section**:
    *   Заголовок: "Забудь про Excel. Наведи порядок..."
    *   CTA (Call to Action): Кнопка "Навести порядок" (веде на `/pricing`).
    *   Підзаголовок про швидкий імпорт.
3.  **Story Section (Проблема)**:
    *   Опис типової ситуації хаосу при масштабуванні.
    *   Список проблем: фінанси, ремонти, графіки.
    *   Блок "Pain Points" (Хто був за кермом?, Графік сиплеться, тощо).
4.  **Value Proposition**: "Garage24 — це концентрація інформації в одному місці".
5.  **Features Grid (Рішення)**: 6 карток з ключовими перевагами (Графік, Водії, Автопарк, Фінанси, ТО, Безпека).
6.  **Integration Section (Uklon)**: Блок про автоматичну синхронізацію з Uklon API.
7.  **Ecosystem Section**:
    *   Мобільний офіс (для менеджерів).
    *   Telegram Бот (для водіїв).
8.  **Simplicity Section**: Порівняння Excel vs Garage24 vs ERP.
9.  **Stats**: Цифри (економія, кількість авто).
10. **How to start**: 4 кроки (Заявка -> Налаштування -> Навчання -> Спокій).
11. **CTA Footer**: "Порядок коштує дешевше, ніж хаос". Кнопка "Спробувати безкоштовно" (веде на `/pricing`).
12. **Footer (`partials.footer`)**: Посилання на розділи, контакти, лінки на Privacy/Terms (модалки).

### 2.2. Можливості (`/features`)
**Мета:** Детально розкрити функціонал для зацікавлених користувачів.
**View:** `features.blade.php`

**Смислові блоки:**
1.  **Header**: Заголовок та короткий опис.
2.  **Features List (динамічний)**: Виводиться з масиву в контролері.
    *   **Головна панель (Dashboard)**: Моніторинг, нагадування.
    *   **Управління автопарком**: Досьє авто, QR-коди.
    *   **Водії та HR**: Профілі, Telegram-бот, онбординг.
    *   **Розумний графік**: Матриця змін, контроль конфліктів.
    *   **ТО**: Журнал робіт, фінанси, Issue Reporting.
    *   **Фінанси**: Транзакції, баланси, категорії.
    *   **Інтеграції**: Uklon API.
    *   **Адміністрування**: Ролі (RBAC), Аудит.
    *   **Документообіг**: Страховки, договори.
    *   **Мобільність**: Адаптивність.
3.  **CTA Block**: "Готові спробувати?" -> Кнопка на `/pricing`.

### 2.3. Кому підійде (`/target`)
**Мета:** Сегментація аудиторії, показати розуміння специфічних болей.
**View:** `target.blade.php`

**Смислові блоки:**
1.  **Header**: Заголовок.
2.  **Personas (Картки персонажів)**:
    *   **Партнери-власники**: Біль - суперечки про гроші. Рішення - прозорість.
    *   **Власник-Операціоніст**: Біль - "живе в гаражі". Рішення - мобільний офіс.
    *   **Інвестор**: Біль - недовіра керуючому. Рішення - аудит та інтеграції.
    *   **Масштабування (10+ авто)**: Біль - хаос в Excel. Рішення - системність.
3.  **Reviews (Відгуки)**: Реальні історії клієнтів (Дмитро, Олександр, Андрій).
4.  **CTA**: Кнопка "Спробувати безкоштовно" (веде на `/pricing`).

### 2.4. Тарифи (`/pricing`)
**Мета:** Вибір тарифного плану та ініціація покупки (заявки).
**View:** `pricing.blade.php`

**Смислові блоки:**
1.  **Header**: Заголовок, бейдж про 14 днів trial.
2.  **Billing Toggle**: Перемикач "Щомісяця / Щорічно (-20%)". Реалізовано через Alpine.js.
3.  **Pricing Grid**:
    *   **Plan Card (Basic)**: Ціна, опис, список функцій. Кнопка викликає модалку замовлення.
    *   **Plan Card (Pro)**: Виділена як "Popular". Розширений функціонал. Кнопка викликає модалку.
4.  **Enterprise Block**: Для великих клієнтів. Кнопка "Обговорити варіант" (викликає модалку).

### 2.5. Контакти (`/contacts`)
**Мета:** Збір лідів (питання) та перенаправлення існуючих клієнтів на підтримку.
**View:** `contacts.blade.php`

**Смислові блоки:**
1.  **Header**: Заголовок.
2.  **Lead Form (Нові клієнти)**: Форма (Ім'я, Email, Телефон, Питання). reCAPTCHA. Відправка на `/api/lead`.
3.  **Client Block (Існуючі клієнти)**: Пояснення, що для техпідтримки краще писати в тікети. Посилання на `app.g24.com.ua/support`. Email підтримки.

### 2.6. Блог (`/blog`)
**Мета:** SEO, контент-маркетинг, новини продукту.
**View:** `blog.index.blade.php`, `blog.post.blade.php`

**Смислові блоки:**
1.  **Index**: Список статей (Дата, Заголовок, Прев'ю). Пошук по блогу.
2.  **Post**: Контент статті (Markdown), навігація (попередня/наступна стаття). Підсвічування тексту при пошуку.

### 2.7. Документація (`/docs`)
**Мета:** Self-service підтримка користувачів.
**View:** `docs.index.blade.php`, `docs.page.blade.php`

**Смислові блоки:**
1.  **Index**:
    *   Пошук по документації.
    *   Категорії (Початок роботи, Основний функціонал, Фінанси, Адміністрування, Додатково).
    *   Картки статей.
    *   Блок "Не знайшли відповідь?" (кнопка на підтримку).
2.  **Page**:
    *   Sidebar: Дерево навігації (акордеон на мобільному).
    *   Content: Текст статті (Markdown).
    *   Navigation: Кнопки "Попередня / Наступна стаття".

## 3. Модальні вікна та інтерактивні елементи

Всі модальні вікна реалізовані через **Alpine.js** і підключаються в `footer.blade.php`. Викликаються через події `$dispatch()`.

### 3.1. Модалка замовлення (`partials/modal-form.blade.php`)
*   **Подія виклику:** `open-order-modal`
*   **Параметри:** `{ plan: 'Назва тарифу' }`
*   **Де викликається:**
    *   Сторінка `/pricing` (кнопки тарифів).
    *   Сторінка `/docs` (кнопка "Написати в підтримку").
    *   Сторінка `/features` (CTA блок, якщо налаштовано).
*   **Функціонал:**
    *   Форма: Ім'я, Email, Компанія, Телефон, Тариф (hidden), Чекбокс згоди.
    *   Валідація: HTML5 + JS перевірка згоди.
    *   reCAPTCHA v2.
    *   Відправка POST на `/api/lead`.
    *   Стани: Loading, Success, Error.

### 3.2. Текстова модалка (`partials/modal-text.blade.php`)
*   **Подія виклику:** `open-text-modal`
*   **Параметри:** `{ title: 'Заголовок', slug: 'ім'я_файлу' }`
*   **Де викликається:**
    *   Footer (посилання "Політика конфіденційності", "Угода користувача").
    *   Cookie Banner.
    *   Модалка замовлення (посилання в чекбоксі згоди).
*   **Функціонал:**
    *   Завантажує контент через AJAX (`/api/page/{slug}`).
    *   Відображає HTML.

### 3.3. Cookie Banner (`partials/cookie-consent.blade.php`)
*   **Логіка:** Показується, якщо в `localStorage` немає ключа `cookie_accepted`.
*   **Функціонал:** Кнопка "Зрозуміло" ховає банер і записує ключ. Посилання на Privacy Policy відкриває текстову модалку.

## 4. Технічні деталі

*   **Фреймворк:** Leaf PHP (Micro-framework).
*   **Шаблонізатор:** Blade.
*   **Frontend:** Alpine.js (інтерактивність), CSS (кастомні стилі, змінні CSS).
*   **Контент:** Markdown файли (для блогу, документації та статичних сторінок).
*   **Маршрутизація:** `app/routes.php`.
*   **Контролери:** `app/Controllers/`.
*   **Сервіси:**
    *   `MarkdownService`: Парсинг .md файлів.
    *   `LeadController`: Обробка заявок.
    *   `SearchController`: Пошук по файлах.

## 5. Файлова структура контенту
*   `content/blog/*.md` - Статті блогу.
*   `content/docs/*.md` - Статті документації.
*   `content/docs/menu.json` - Структура меню документації.
*   `content/pages/*.md` - Статичні сторінки (Privacy, Terms).

# API Реєстрації Парку (для Лендінгу)

Цей документ описує публічні ендпоінти для інтеграції форми реєстрації на лендінгу з SaaS платформою.

**Base URL:** `https://app.your-domain.com/api/v1/public/landing`
**Auth:** Не потрібна (публічний доступ).
**Rate Limit:** 60 запитів / хв.
**CORS:** Дозволено для доменів, вказаних у конфігурації.

---

## 1. Отримання конфігурації (Плани)
Отримує список доступних тарифних планів для відображення у формі (ціни, назви).

- **Method:** `GET`
- **Endpoint:** `/config`

### Приклад відповіді (200 OK):

```json
{
  "plans": [
    {
      "id": 1,
      "slug": "standard-monthly-2026",
      "name": "Стандарт (Щомісячний)",
      "price_monthly": "1000.00",
      "price_yearly": "0.00",
      "price_per_car": "200.00",
      "currency": "UAH"
    },
    {
      "id": 2,
      "slug": "yearly-2026",
      "name": "Річний (Знижка 50% на авто)",
      "price_monthly": "0.00",
      "price_yearly": "12000.00",
      "price_per_car": "100.00",
      "currency": "UAH"
    }
  ]
}
```

## 2. Реєстрація Парку
Відправляє дані для створення нового парку. Система автоматично створює парк, власника та відправляє лист активації.

- **Method:** `POST`
- **Endpoint:** `/register`

### Тіло запиту (JSON):

```json
{
  "park_name": "Назва Парку",
  "owner_name": "Ім'я Власника",
  "owner_email": "owner@mail.com"
}
```

| Поле | Тип | Обов'язкове | Опис |
|---|---|---|---|
| `park_name` | String | Так | Назва компанії/парку (макс. 255 символів). |
| `owner_name` | String | Так | ПІБ власника (макс. 255 символів). |
| `owner_email` | Email | Так | Email власника (макс. 255 символів). |

### Приклад успішної відповіді (201 Created):

```json
{
  "success": true,
  "message": "Парк успішно зареєстровано. Перевірте вашу пошту для активації акаунту.",
  "park_slug": "nazva-parku-x7z9q"
}
```

### Приклад помилки валідації (422 Unprocessable Entity):

```json
{
  "message": "The given data was invalid.",
  "errors": {
    "owner_email": [
      "The owner email has already been taken."
    ]
  }
}
```

---

### Логіка роботи фронтенду:
1.  При завантаженні сторінки/модалки зробити запит `GET /config`, щоб отримати актуальні ціни (опціонально, якщо потрібно показувати їх у формі).
2.  Зібрати дані форми.
3.  Відправити `POST /register`.
4.  Обробити відповідь:
    *   **Успіх:** Показати повідомлення "Дякуємо! Лист з посиланням на активацію відправлено на ваш email".
    *   **Помилка:** Показати повідомлення про помилку (наприклад, "Цей email вже зареєстрований").
